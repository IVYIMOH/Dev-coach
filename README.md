# Design Coach 🎨

An installable 18-Day Brutal Product Designer Challenge Tracker with an AI Accountability Coach.

Design Coach pushes aspiring and transitioning product designers to master end-to-end product design, eliminate passive consumption, and produce undeniable portfolio artifacts in **18 intensive days**—demanding proof before celebrating output.

---

## 🌟 The 18-Day Brutal Roadmap

Divided into 3 Six-Day Sprints:

### **Sprint 1 (Days 1–6): Problem Discovery & Strategic Architecture**
- **Day 1: Problem Space Dissection & User Archetype**
  - *Learn (45m)*: Opportunity Solution Trees & 5 Whys root cause analysis.
  - *Practice*: Deconstruct 3 competitor product drop-off points.
  - *Ship*: **1-Page Problem Canvas & Target User Archetype** with behavioral triggers.
- **Day 2: Guerilla User Research & Interview Extraction**
  - *Learn (45m)*: "The Mom Test" interview mechanics—extracting past behavior without leading bias.
  - *Practice*: Write a 6-question user interview script focused on past friction and workarounds.
  - *Ship*: **User Research Synthesis Matrix** from 2 live interviews or 20+ verified community complaint threads.
- **Day 3: Jobs-To-Be-Done (JTBD) & Switching Anxieties**
  - *Learn (45m)*: Clayton Christensen JTBD framework: Functional, Emotional, and Social user jobs.
  - *Practice*: Map the 4 Forces of Progress (Push, Pull, Habit, Anxiety) for your target user.
  - *Ship*: **FigJam JTBD Hierarchy Board** with 3 prioritized, outcome-driven job statements.
- **Day 4: Problem Framing, How Might We (HMW) & MVP Scoping**
  - *Learn (45m)*: MoSCoW scoping and carving the Smallest Shippable Value wedge.
  - *Practice*: Draft 10 diverging HMW statements and plot on an Impact vs. Complexity 2x2 matrix.
  - *Ship*: **Signed-Off MVP Boundary Document** locking the core loop and explicitly cutting non-essential scope.
- **Day 5: Information Architecture & Complex User Flows**
  - *Learn (45m)*: Object-Oriented UX (OOUX), navigation models, and decision-tree edge casing.
  - *Practice*: Map the primary user flow including 3 branch decisions, 2 empty states, and 2 error states.
  - *Ship*: **End-to-End User Flow Architecture Diagram in FigJam/Figma** with logic diamonds and system responses.
- **Day 6: Speed Wireframing & Crazy 8s Divergence**
  - *Learn (45m)*: Fast low-fi divergence techniques; decoupling structural layout from aesthetic styling.
  - *Practice*: Run two timeboxed 8-minute Crazy Eights sketching rounds for the highest friction product screen.
  - *Ship*: **Clickable Low-Fidelity Wireframe Flow (10+ screens)** in Figma with zero dead ends.

---

### **Sprint 2 (Days 7–12): Figma Systems, Visual Polish & Interactive Prototyping**
- **Day 7: Design Tokens & Semantic Variable Architecture**
  - *Learn (45m)*: Multi-tier design token architecture (Global -> Semantic -> Component) & Figma Variables.
  - *Practice*: Build semantic color modes (light/dark) and an 8pt spatial grid scale in Figma Variables.
  - *Ship*: **Figma Design Tokens Library** with published semantic variables and modular typographic scale.
- **Day 8: High-Yield Components, Auto Layout 5.0 & Variants**
  - *Learn (45m)*: Advanced Auto Layout: min/max bounds, nested hugging/filling, and slot architecture.
  - *Practice*: Build responsive form input and button component sets with all states (default, hover, focus, disabled, loading).
  - *Ship*: **Production-Grade UI Component Set** (Buttons, Form Inputs, Modal, Navigation) with zero broken constraints.
- **Day 9: Visual Craft, Typographic Hierarchy & Data Display**
  - *Learn (45m)*: Gestalt grouping, optical alignment vs geometric centering, and high-density scannability.
  - *Practice*: Convert Day 6 low-fi wireframes to high-fidelity utilizing design tokens and spatial rhythm.
  - *Ship*: **First 5 High-Fidelity Production Screens in Figma** with pristine visual hierarchy and zero arbitrary values.
- **Day 10: State Machine Matrix (Empty, Partial, Error, Edge Cases)**
  - *Learn (45m)*: The 9 UI States: Ideal, Empty, Loading, Partial, Error, Success, Offline, Denied, and Extreme Data Overflow.
  - *Practice*: Stress-test UI components against 120-character strings, missing image avatars, and network dropouts.
  - *Ship*: **Complete Edge Case & UI State Board** covering all 9 states for the primary product flow.
- **Day 11: High-Fidelity Micro-Interactions & Smart Animate**
  - *Learn (45m)*: Interaction choreographies, spring physics curves, and cognitive continuity during state transitions.
  - *Practice*: Wire interactive component variants with hover delays, drawer slides, and smart-animate sheet transitions.
  - *Ship*: **Fluid End-to-End Interactive Clickable Prototype in Figma** ready for live usability testing.
- **Day 12: Usability Testing Under Fire & Protocol Execution**
  - *Learn (45m)*: Think-aloud testing protocols, objective observation vs defensive designer bias.
  - *Practice*: Run 2 unguided user test sessions with strict scenario prompts (e.g. "Complete task X without assistance").
  - *Ship*: **Usability Test Session Recording & Blocker Severity Matrix** (Critical/High/Med) with user timestamps.

---

### **Sprint 3 (Days 13–18): Hardening, Engineering Handoff & Portfolio Launch**
- **Day 13: Rapid Feedback Iteration & UX Triage**
  - *Learn (45m)*: Feedback triage: distinguishing individual user preference from architectural usability failure.
  - *Practice*: Redesign the two biggest points of drop-off or confusion identified during usability testing.
  - *Ship*: **Before & After Iteration Board in Figma** documenting tested user friction and verified UI solutions.
- **Day 14: WCAG 2.2 AA Accessibility & Assistive Tech Audit**
  - *Learn (45m)*: WCAG 2.2 AA standards: 4.5:1 text contrast, 3:1 UI components, 48x48px touch targets, focus rings.
  - *Practice*: Run Stark / Adee contrast audit across all screens and verify keyboard focus tab order.
  - *Ship*: **Accessibility Compliance Scorecard** verifying contrast ratios, touch targets, and ARIA labels across the app.
- **Day 15: UX Writing, Microcopy & Error Recovery**
  - *Learn (45m)*: Microcopy precision: writing error recovery copy (Problem + Cause + Clear Actionable Solution).
  - *Practice*: Rewrite all button CTAs, tooltips, empty-state descriptions, and destructive confirmation modals.
  - *Ship*: **UI Copy Matrix & Content Style Guide frame in Figma** covering tone of voice and alert taxonomy.
- **Day 16: Product Analytics, North Star Metric & Experimentation Spec**
  - *Learn (45m)*: Event telemetry schemas, funnel drop-off calculation, activation definitions, and A/B test hypotheses.
  - *Practice*: Define the core telemetry funnel (viewed_screen -> clicked_cta -> completed_step -> reached_aha_moment).
  - *Ship*: **1-Page Product Telemetry & Experimentation Spec** defining primary metric, secondary metrics, and event taxonomy.
- **Day 17: Production Dev Handoff & Engineering Specification**
  - *Learn (45m)*: Dev mode in Figma, redlining, token variable mapping, and responsive CSS flexbox/grid annotations.
  - *Practice*: Annotate spacing tokens, responsive breakpoint behaviors (360px, 768px, 1280px), and asset export rules.
  - *Ship*: **Complete Dev-Ready Handoff Specification in Figma** with redline annotations, asset exports, and state matrices.
- **Day 18: Brutal Portfolio Case Study & Public Defense**
  - *Learn (45m)*: Anatomy of an Elite Case Study: Hiring managers skim in 90s; lead with problem, metrics, and trade-offs.
  - *Practice*: Assemble hero mockups, before/after artifacts, usability data quotes, and lessons learned.
  - *Ship*: **Live Published Portfolio Case Study** (Notion, Personal Domain, or Medium) with hero mockups and clickable prototype link.
